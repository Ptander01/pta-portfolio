# Photos of Patrick

Drop files here with these exact names and they appear on the site with no
code change — each slot probes for its file and stays hidden until it exists.

| Filename            | Appears on                          | The photo |
|---------------------|-------------------------------------|-----------|
| `portrait.jpg`      | `/about` hero, beside the headline  | Full-body outdoor, flannel + quilted vest, field at dusk |
| `headshot.jpg`      | `/resume`, beside the download      | Navy suit, orange striped bowtie, greenery behind |
| `speaking.jpg`      | `/resume`, Speaking & Presenting    | Red bowtie, light blue shirt — the conference shot |
| `desk.jpg`          | `/about`, "Off the clock"           | Journal, candle, window — the writing desk |

`.jpg`, `.png`, or `.webp` all work; the extension in the filename must match
the actual file. Portrait orientation is expected for `portrait.jpg`, square-ish
for the two headshots, portrait for `desk.jpg`.

No resizing needed — but anything over ~2500px wide is worth converting to
WebP first, the same way the gallery macros are handled.
